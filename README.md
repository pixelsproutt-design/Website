# Pixel Sprout Website

Marketing homepage for **Pixel Sprout** — *Where Businesses Take Root*.

Built to the MVP scope in `pixel-sprout-build-spec-mvp.md` (homepage only, scroll-linked GSAP animations, Get Quote modal).

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Next.js dev server |
| `npm run build` | Production build |
| `npm run start` | Start production server |
| `npm run lint` | ESLint |

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS
- GSAP + ScrollTrigger

## Spec documents

- `pixel-sprout-website-prd.md` — full product requirements
- `pixel-sprout-build-spec-mvp.md` — MVP build scope (homepage)
